# COVID-19 Data Analysis Project

## Overview
This project analyzes COVID-19 data using Python, Pandas, NumPy, Matplotlib, and Seaborn

## Dataset
Source: Our World in Data (OWID)

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset
Download from:
https://covid.ourworldindata.org/data/owid-covid-data.csv

## Analysis Performed
- Data cleaning and handling missing values
- Global COVID cases and deaths
- Top countries by cases and vaccinations
- Death rate analysis
- Time-series analysis
- Country-level analysis (India)
- Continent-wise comparison

## Key Insights
- United States had the highest number of COVID-19 cases
- Asia was the most affected continent
- Peak wave occurred around January 2022
- China, India, and USA led in vaccinations

## Visualizations
- Global cases trend
- Country-level trends
- Vaccination comparison
- Cases vs deaths relationship
